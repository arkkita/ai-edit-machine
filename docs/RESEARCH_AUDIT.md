# AI Edit Machine — Current Technology Audit

**Audit date:** 2026-08-15  
**Target:** local Windows desktop application, RTX 4060 Laptop GPU (8 GB VRAM), 64 GB RAM  
**Status:** Milestone 0 audit complete; Milestone 1 approved on 2026-08-15; focused M1.1 calibration authorized on 2026-08-19. No Milestone 2 footage/video implementation is authorized.

This audit uses current first-party documentation wherever it exists. Prices and terms can change; every production provider must be checked again at runtime/on release. Licensing notes are engineering risk flags, not legal advice.

## Executive decision

The practical design is **local media truth + cloud semantic reasoning + deterministic compilation**:

- Tauri 2/React provides the desktop shell. A Rust core owns paths, secrets, processes, and SQLite.
- A persistent Python worker communicates over UTF-8 LF-delimited JSON objects on inherited stdin/stdout (4 MiB max frame, protocol-only stdout). The proposed localhost FastAPI server is rejected for v1.
- TVmaze plus official network/studio pages seed release facts. TMDB is disabled because its current standard terms prohibit connection to an AI/ML application. TheTVDB is conditional on product-tier approval.
- `grok-4.6` with X Search remains a desired qualitative-fandom configuration, but the 2026-08-19 first-party recheck did not establish that model ID. xAI therefore stays disabled. OpenAI web search is the primary page-opening verifier and is not treated as a popularity census.
- Gemini 3.7 Flash remains the product's intended future long-video candidate, with documented Gemini 3.6 Flash as a possible rollback, but the 2026-08-19 first-party recheck did not establish the 3.7 ID. No M2 adapter is authorized; the mandatory pre-M2 study must resolve the current model/architecture and local subtitle/ASR/shot tools still own exact timing.
- FFmpeg compiles a validated EDL. LLM text is never executed as a command and never defines exact cut frames, effect keyframes, crop paths, or arbitrary velocity curves.
- Current Topaz Video has no supported public CLI. Finishing begins with a manual handoff; the user's installed legacy Topaz Video AI 7.1.0 may receive a separate, explicit, version-gated adapter later.
- After Effects automation is deferred to the finishing milestone and uses one fixed audited ExtendScript plus `aerender`, never generated script.

### M1.1 provider-role and model audit — 2026-08-19

The exact one-result regression was diagnosed before changing models. TVmaze
found at least 94 matching current shows, but the verifier deeply searched only
five titles; only one then accumulated the two independent current discussion
owners needed by the evidence gate. The deployed intent had no typed audience,
platform-fit, or creative-edit facets, and the deterministic fallback lacked an
audience score. Deduplication, schema validation, Rust serialization, the UI,
provider failure, and the cost cap did not remove additional qualified cards.

The dated bake-off packet in `evals/2026-08-19-m1.1/model-bakeoff.json` evaluates
all requested roles without turning documentation review into fake measured
quality:

|---|---|---|

| Current — GPT-5.6 Luna | Existing WinCred, resolved-model preflight, price card, Responses endpoint, strict schemas, and replay path remain operational. | Retain as production default while M1.1 changes allocation, ranking, and concept synthesis around it; attach exact live measurements to the completion report. |

The reusable offline harness accepts one evidence-packet ID for all contenders
and requires complete relevance, recall, precision, intent, currentness,
evidence, footage, narrative, creativity, coherence, hallucination-avoidance,
structured-output, latency, and cost measurements before it will name a best
model. Unrun/blocked configurations are required to have null scores.

The rank-profile bake-off is measured now: the selected
`m1.1-intent-editorial-v1` profile obtains 1.000 pairwise accuracy on the dated
component packet. A freshness-heavy control obtains 0.833 and incorrectly puts
a brand-new weak-audience candidate above a less-fresh audience-aligned one.
This is the evidence for the production rank profile; its weights are not a
claim of scientific universality and remain versioned evaluation parameters.

## Media stack and hardware implications

- **Subtitle-first:** extract embedded/sidecar text before spending GPU time. Use WhisperX only when needed, with faster-whisper word timestamps as a simpler fallback. Speaker clusters are not character identities.
- **GPU scheduling:** ASR → unload → optional embedding/vision → unload → NVENC. Beat detection can stay on CPU. Start ASR at batch 1–4.
- **Gemini temporal limits:** at documented sampling rates, a 45-minute episode is roughly 270k input tokens at low resolution or 810k at default. The current proposal is an independently cached coarse source map plus targeted high-detail rescans; it is not final. The pre-M2 study must compare native multi-video reasoning, provider caching/reuse, hierarchical scene memory, multimodal retrieval, adaptive sampling, and hybrid local/cloud alternatives while measuring subtle-reaction loss.
- **Exact timing:** media PTS/timebase and local shot boundaries are authoritative. Cloud timestamps are approximate locators with uncertainty until verified locally.
- **Reframing:** center/manual crop is shippable. A face-tracking prototype must reset at cuts and enforce dead zones/pan speed; identity recognition is not required.
- **Packaging:** the target user does not install Python, uv, FFmpeg, or Rust. The eventual signed installer includes only audited binaries that may legally be redistributed.

## Architecture changes made after the audit

1. Replaced FastAPI/localhost IPC with a supervised stdio sidecar protocol.
2. Disabled TMDB instead of treating its free key as a harmless metadata dependency.
3. Added OpenAI web search as the canonical page verifier and policy-aware evidence archive input.
4. Originally named Grok 4.6 as the desired X research default with a cheaper fallback; the M1.1 first-party recheck supersedes any assumption that the requested ID exists, so xAI remains disabled pending exact preflight and pricing.
5. Kept Gemini 3.7 Flash as a requested future candidate with documented 3.6 as a possible rollback and local timestamp authority. The M1.1 recheck could not establish 3.7, and no video adapter is authorized before the mandatory pre-M2 study.
6. Made subtitles and lightweight text retrieval the baseline; local multimodal embeddings and SAM moved out of v1.
7. Split current Topaz manual handoff from the user's separately versioned legacy Topaz Video AI asset.
8. Restricted AE to a fixed template/work-order adapter and made the supplied AEP—not re-created settings—the canonical look asset.
9. Narrowed the supported commercial target to Windows 11 x64 with signed, reproducible binaries.
10. Replaced M0’s fixed 3–5-card acceptance target with 1–5 independently qualified cards. This implements the approved “small number of genuinely useful opportunities” clarification and the explicit permission to abstain; padding one strong result with weaker cards would violate the evidence and minimum-footage quality bar.

11. A 2026-08-15 M1 live smoke exposed two provider-boundary defects without changing the selected model.
